# Security policy

Report suspected vulnerabilities privately to the repository owner before a
public issue when disclosure could expose users.

Do not include credentials, private keys, tokens, customer data, or live
exploit payloads in reports or fixtures.

`v0.1.x` is an alpha reference implementation. A passing schema, guard, test
matrix, or bundle verifier is not a security certification. Causal Cell v0.1
does not provide sandboxing, cryptographic identity, durable distributed replay
protection, response truth, blockchain finality, or external exactly-once
execution.
